## установка PHP
так как у меня arch linux установка будет из официального репозитория arch `pacman`

1. проверим обнавления системы
```bash
sudo pacman -Syu
```
> обнавления всех системных пакетовв

2. установка PHP
установку можно произвести и через `curl` но я буду устанавливать из `pacman`

```bash
sudo pacman -S php
```

3. проверка работоспособности
для теста выведем версию `php`

```bash
php -v
```

## Главные отличия `echo` от `print`:

1. **Сколько можно передать:** `echo` может выводить сразу несколько штук через запятую (например, `echo "A", "B";`), а `print` — только одну.
2. **Результат работы:** `echo` ничего не возвращает после вывода, а `print` всегда возвращает единицу (`1`), поэтому его иногда можно вставить прямо в формулы или присвоить переменной.
3. **Скорость:** `echo` работает капельку быстрее, потому что не тратит время на возвращение этогй `1`.
