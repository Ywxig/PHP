### 2. Ход выполнения работы

#### Задание 1. Динамическое расписание на основе текущего дня недели
Был разработан скрипт, определяющий текущий день недели с помощью функции `date('N')` (где понедельник — 1, воскресенье — 7). В зависимости от полученного дня недели формируется таблица с расписанием сотрудников:
* **John Styles**: работает по понедельникам, средам и пятницам (`8:00-12:00`), в остальные дни — «Нерабочий день».
* **Jane Doe**: работает по вторникам, четвергам и субботам (`12:00-16:00`), в остальные дни — «Нерабочий день».

**Фрагмент кода (определение условий и вывод таблицы):**
```php
$dayOfWeek = (int)date('N');

// График для John Styles (понедельник, среда, пятница)
if (in_array($dayOfWeek, [1, 3, 5])) {
    $johnSchedule = '8:00-12:00';
} else {
    $johnSchedule = 'Нерабочий день';
}

// График для Jane Doe (вторник, четверг, суббота)
if (in_array($dayOfWeek, [2, 4, 6])) {
    $janeSchedule = '12:00-16:00';
} else {
    $janeSchedule = 'Нерабочий день';
}
```

#### Задание 2. Циклы в PHP (`for`, `while`, `do-while`)
Исходный цикл `for` был дополнен выводом промежуточных значений переменных `$a` и `$b` на каждом шаге. Аналогичная логика была повторно реализована с использованием операторов `while` и `do-while`.

**1. Цикл `for` с выводом промежуточных шагов:**
```php
$a = 0;
$b = 0;

for ($i = 0; $i <= 5; $i++) {
   $a += 10;
   $b += 5;
   echo "Шаг $i: a = $a, b = $b\n";
}
echo "End of the loop: a = $a, b = $b";
```

**2. Аналог с использованием цикла `while`:**
```php
$a = 0;
$b = 0;
$i = 0;

while ($i <= 5) {
   $a += 10;
   $b += 5;
   echo "Шаг $i: a = $a, b = $b\n";
   $i++;
}
echo "End of the loop: a = $a, b = $b";
```

**3. Аналог с использованием цикла `do-while`:**
```php
$a = 0;
$b = 0;
$i = 0;

do {
   $a += 10;
   $b += 5;
   echo "Шаг $i: a = $a, b = $b\n";
   $i++;
} while ($i <= 5);
echo "End of the loop: a = $a, b = $b";
```
